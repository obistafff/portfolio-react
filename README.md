# Portfolio – John Doe

Ce projet est un site portfolio développé avec **React** et **Vite**.
Il présente les services, réalisations, compétences et informations de contact
d’un développeur web.

Le site est composé de plusieurs pages :
- Accueil
- Services
- Portfolio
- Contact
- Mentions légales

---

## Technologies utilisées

- React
- Vite
- JavaScript
- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons

---

## Prérequis

Avant d’installer et de lancer le projet, assurez-vous d’avoir installé :

- **Node.js** (version 18 ou supérieure recommandée)
- **npm** (fourni avec Node.js)

---

## Installation

1. Cloner le dépôt GitHub :
```bash
git clone https://github.com/obistafff/portfolio-react.git

```bash
cd portfolio-react

```bash
npm install

```bash
npm run dev

Le projet est ensuite accessible à l’adresse indiquée dans le terminal, généralement http://localhost:5173
